# YenTick (円高円安インジケータ付きグラフ表示Chrome拡張機能)

YenTick（エンティック）は、米ドル/日本円（USD/JPY）の最新為替レートと過去24時間の推移グラフを、Google Chromeブラウザのツールバーから一目で美しく確認できる拡張機能です。
外部為替API（Open Exchange Rates）から取得したデータを元に、リアルタイムのレートとトレンドをプレミアム感のあるダークテーマUIで可視化します。

---

## 🌟 主な機能

1. **リアルタイム為替レート表示**
   - 最新のUSD/JPY為替レートを、小数点以下3桁（例: `148.250`）で大きく見やすく表示します。
   - オンライン時は「LIVE」、オフライン時は「OFFLINE（最終更新日時）」をステータスインジケータで明示します。

2. **滑らかなSVG折れ線グラフ**
   - 過去24時間のレート推移を、美しいBézier（ベジェ）曲線とサイバーシアンのグラデーションで描画します。
   - グラフの縦軸（Y軸）スケールは、過去24時間の最高値と最安値に応じて自動でフィットし、わずかな値動きの変化も直感的に判別できます。

3. **現在値インジケータ（動的追従）**
   - グラフの右端に確保された専用マージン（50px）内で、現在レートの高さに合わせて「矢印（◀）」と「数値ラベル」が動的に上下追従します。
   - レートが急変動して履歴範囲外に飛び出した場合も、描画エリア内に安全に収まるクリッピング処理を施しています。

4. **堅牢なオフライン対応（キャッシュ・タイムアウト制御）**
   - API通信には5秒のタイムアウト制限を設けており、接続不良時もブラウザをフリーズさせません。
   - 取得したデータはブラウザのローカルストレージに24時間有効なキャッシュとして保存されます。オフライン起動時は自動的にキャッシュからグラフを復元して「縮退運転」を行います。
   - 万が一キャッシュもなく完全にオフラインの場合は、エラー画面とともに手動で復旧を試みられる「再試行 (RETRY CONNECTION)」ボタンを提供します。

## 🛠 インストール方法（簡単セットアップ）

PCの操作やGoogle Chromeの拡張機能の開発に詳しくない方でも、以下の手順に沿って簡単にインストールできます。

### ステップ 1: プログラムの準備
1. GitHubからリポジトリをダウンロード（「Code」ボタンから「Download ZIP」を選択）し、任意の場所に解凍します。
   ※フォルダの中に `manifest.json` や `popup.html` などのファイルが直接入っていることを確認してください。

### ステップ 2: Chromeの拡張機能管理画面を開く
1. Google Chromeブラウザを起動します。
2. 画面右上にある **「︙」（Google Chromeの設定）** アイコンをクリックします。
3. メニューから **「拡張機能」** ＞ **「拡張機能を管理」** を選択します。
   ※または、アドレスバーに `chrome://extensions/` と直接入力してEnterキーを押すことでも開けます。

### ステップ 3: デベロッパーモードを有効にする
1. 拡張機能画面の右右上にある **「デベロッパー モード」** のスイッチを **オン（有効）** にします。
   （スイッチをオンにすると、画面上部に新しいボタンが表示されます）

### ステップ 4: フォルダを読み込む
1. 画面左上に表示された **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
2. ファイル選択ダイアログが表示されるので、**「ステップ 1」で解凍したフォルダ（`manifest.json` が入っているフォルダ自体）** を選択し、**「フォルダーの選択」** をクリックします。

🎉 **これでインストールは完了です！**
Chromeのツールバー（パズルピースのアイコン 🧩）をクリックし、一覧にある **YenTick** をピン留めすると、常にアイコンを表示させることができます。

## 💡 使用方法

- **ポップアップの起動**:
  ツールバーのYenTickアイコン（グラフと円のデザイン）をクリックするだけで、最新のドル円レートとグラフが約100ms以内の高速さで起動・表示されます。
- **手動でのデータ更新 / 再試行**:
  インターネット接続エラーなどでエラー画面が表示された場合、画面下部の **「RETRY CONNECTION (再試行)」** ボタンをクリックすることで、ローディングを挟んで再度最新データの取得を試みることができます。
